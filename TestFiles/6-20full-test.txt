6-20 FULL TEST CASE SPECIFICATION - HSCSAPI
===========================================

التاريخ المرجعي: 20 يونيو 2026
النطاق: جميع HTTP endpoints الحالية (96 endpoint) + ChatHub + NotificationHub
التنظيم: Grouped by Controller

مهم جداً:
- هذا الملف هو Test Case Specification شامل، وليس ادعاء أن جميع الحالات نفذت على قاعدة الإنتاج.
- الحالات التي تحتاج بيانات تحفظ/تحذف يجب تنفيذها على قاعدة TEST معزولة ومجهزة بالـfixtures أدناه.
- الاختبارات الآلية الموجودة حالياً تغطي المحادثات وSignalR وتخزين الملفات. نتيجة تشغيلها تسجل في قسم Execution Summary بعد التشغيل.
- ممنوع تنفيذ حالات DELETE أو التسجيل الجماعي على قاعدة الإنتاج.


أعمدة كل Test Case
==================

ID: رقم الحالة.
Type: SUCCESS / VALIDATION / AUTH / AUTHORIZATION / NOT_FOUND / CONFLICT / FILE / PAGING / SECURITY / FAILURE.
Preconditions: البيانات والحساب المطلوبان قبل التنفيذ.
Input/Steps: الطلب الذي ينفذ.
Expected: HTTP status + شكل body + أثر قاعدة البيانات أو الحدث المتوقع.
Execution: PLANNED ما لم يذكر PASS من اختبار آلي منفذ.


TEST DATA FIXTURES
==================

CL-A: عيادة A صالحة.
CL-B: عيادة B صالحة.
U-SA: SuperAdmin مؤكد البريد.
U-SEC-A: Secretary تابع لـCL-A ومديرها.
U-SEC-A2: Secretary تابع لـCL-A وليس مديراً.
U-SEC-B: Secretary تابع لـCL-B ومديرها.
U-SEC-FREE: Secretary غير تابع لأي عيادة.
U-PAT-A: Patient مؤكد تابع لـCL-A.
U-PAT-A2: Patient آخر تابع لـCL-A.
U-PAT-B: Patient تابع لـCL-B.
U-DOC-A: Doctor تابع لـCL-A ورخصته فريدة.
U-DOC-B: Doctor تابع لـCL-B.
U-LAB-A / U-LAB-B: LaboratoryTechnologist لكل عيادة.
U-RAD-A / U-RAD-B: RadiologyTechnologist لكل عيادة.
U-AM: AuthorizedMember مؤكد البريد.
U-UNVERIFIED: مستخدم مسجل ولم يؤكد البريد.
APP-A-FUTURE: موعد مستقبلي بين U-DOC-A وU-PAT-A دون ملفات.
APP-A-WITH-FILE: موعد لديه MedicalFile.
MF-LOW: سجل طبي Low للمريض U-PAT-A وله ملف فعلي.
MF-HIGH: سجل طبي High للمريض U-PAT-A.
INV-PENDING: دعوة Pending من U-PAT-A إلى U-AM.
CHAT-A: محادثة بين U-PAT-A وU-DOC-A.
OUTSIDER: مستخدم مؤكد ليس عضواً في CHAT-A.


GLOBAL CROSS-CUTTING CASES
==========================

GLOBAL-001 | AUTH
Scope: كل endpoint عليه [Authorize].
Input: الطلب بلا Authorization header.
Expected: 401، ولا تغيير في قاعدة البيانات.
Execution: PLANNED لكل endpoint محمي.

GLOBAL-002 | AUTH
Scope: كل endpoint محمي.
Input: Bearer token منتهي أو signature خاطئ.
Expected: 401، ولا يصل الطلب إلى Service.
Execution: PLANNED.

GLOBAL-003 | AUTHORIZATION
Scope: كل endpoint عليه Roles.
Input: token صالح لكن role غير مسموح.
Expected: 403، ولا تغيير في قاعدة البيانات.
Execution: PLANNED.

GLOBAL-004 | VALIDATION
Scope: كل endpoint يستقبل JSON.
Input: JSON غير صالح syntax.
Expected: 400 ValidationProblemDetails.
Execution: PLANNED.

GLOBAL-005 | VALIDATION
Scope: حقول Guid في route والمقيدة بـ:guid.
Input: قيمة مثل abc بدلاً من Guid.
Expected: 404 route not matched.
Execution: PLANNED.

GLOBAL-006 | VALIDATION
Scope: DateOnly/TimeOnly query أو body.
Input: تاريخ 2026-99-99 أو وقت 28:90.
Expected: 400 model-binding validation error.
Execution: PLANNED.

GLOBAL-007 | FAILURE
Scope: جميع endpoints.
Input: محاكاة توقف قاعدة البيانات.
Expected: 500 application/problem+json مع traceId، دون كشف تفاصيل حساسة في Production.
Execution: PLANNED في test environment فقط.

GLOBAL-008 | SECURITY
Scope: string inputs.
Input: HTML/JS مثل <script>alert(1)</script>.
Expected: لا ينفذ الخادم script؛ الفرونت يعرض النص escaped ولا يستخدم innerHTML.
Execution: PLANNED.

GLOBAL-009 | SECURITY
Scope: search/name/email inputs.
Input: SQL injection strings مثل ' OR 1=1 --.
Expected: لا injection لأن EF يستخدم parameterization؛ النتيجة تعامل كنص أو validation failure.
Execution: PLANNED.

GLOBAL-010 | HTTP
Scope: كل endpoint.
Input: HTTP method خاطئ على route صحيح.
Expected: 405 Method Not Allowed أو 404 حسب route matching، دون أثر بيانات.
Execution: PLANNED.

GLOBAL-011 | CANCELLATION
Scope: عمليات طويلة.
Input: إلغاء request من العميل أثناء التنفيذ.
Expected: لا response جزئي؛ middleware يستخدم 499 إذا RequestAborted سبب OperationCanceledException قبل بدء response.
Execution: PLANNED.

GLOBAL-012 | SERIALIZATION
Scope: كل response.
Input: نجاح عادي.
Expected: JSON camelCase، null للحقول الاختيارية، [] للقوائم الفارغة، وعدم ظهور navigation cycles.
Execution: PLANNED.
